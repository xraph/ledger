---
title: Error Handling
description: The sentinel errors in the ledger package, which ones the engine actually returns, and how to check them.
---

The root `ledger` package declares its sentinel errors with `errors.New`. The engine and the stores usually wrap them with `%w` and some context, so check them with `errors.Is`:

```go
sub, err := engine.GetSubscription(ctx, subID)
switch {
case errors.Is(err, ledger.ErrSubscriptionNotFound):
	// unknown ID
case err != nil:
	return err
}
```

Some sentinels are declared but nothing in the module returns them yet. The tables say which.

## General

| Error | Returned when |
|-------|---------------|
| `ErrInvalidInput` | Most validation failures: a plan without a name, slug or currency; a subscription without a tenant or plan; a plan in another app or not active; `Meter` without tenant or app context; a status transition that isn't allowed, such as resuming a subscription that isn't paused; a `ForPeriod` period that doesn't fit the subscription. The wrapped message says which. |
| `ErrAlreadyExists` | A plan slug or coupon code already used in the app, or a second live invoice for a period. |
| `ErrNotFound` | Not returned by the engine. The dashboard contract maps it, and `IsNotFound` checks it. |
| `ErrUnauthorized`, `ErrForbidden` | Declared only. |

## Plans and features

| Error | Returned when |
|-------|---------------|
| `ErrPlanNotFound` | A plan lookup by ID or slug finds nothing. |
| `ErrPlanInUse` | `DeletePlan` on a plan a subscription still uses. Archive it instead. |
| `ErrInvalidPricing` | A negative base price, a base price in another currency, or a tier for a feature the plan doesn't have. |
| `ErrDuplicateFeature` | Two plan features share a key. |
| `ErrInvalidCreditPool` | A credit pool with no key or a repeated key, an amount at or below zero or in another currency, or a feature that is unknown, not metered, or already in another pool. |
| `ErrFeatureNotFound` | A catalog feature lookup finds nothing. |
| `ErrPlanArchived`, `ErrFeatureArchived` | Declared only. Subscribing to an archived plan fails with `ErrInvalidInput`. |

A broken tier ladder fails with `invoice.ErrInvalidTiers`, from the `invoice` package, both in `CreatePlan` and in `GenerateInvoice`.

## Subscriptions

| Error | Returned when |
|-------|---------------|
| `ErrSubscriptionNotFound` | A subscription lookup by ID finds nothing. |
| `ErrNoActiveSubscription` | `GetActiveSubscription` finds no active or trialing subscription for the tenant and app. |
| `ErrSubscriptionCanceled`, `ErrSubscriptionExpired` | Canceling or changing the plan of a subscription that has already ended. |
| `ErrInvalidQuantity` | A negative seat count. |
| `ErrSubscriptionExists`, `ErrInvalidUpgrade`, `ErrInvalidDowngrade`, `ErrTrialExpired` | Declared only. |

## Usage and entitlements

| Error | Returned when |
|-------|---------------|
| `ErrMeterBufferFull` | `Meter` when the 10,000-event buffer is full. Retry later or slow down. |
| `ErrCacheMiss` | A store's `GetCached` has no live entry. The engine treats it as a miss and computes the answer; you only see it if you call the store yourself. |
| `ErrQuotaExceeded`, `ErrHardLimitReached`, `ErrSoftLimitReached`, `ErrNoEntitlement`, `ErrFeatureDisabled` | Declared only. A denied quota check isn't an error: `Entitled` returns a result with `Allowed: false` and a `Reason`. |
| `ErrDuplicateEvent`, `ErrEventTooOld`, `ErrCacheInvalidate` | Declared only. A store skips a usage event whose idempotency key it has already seen, without an error. |

## Invoices

| Error | Returned when |
|-------|---------------|
| `ErrInvoiceNotFound` | An invoice lookup by ID finds nothing. |
| `ErrInvoiceFinalized` | `FinalizeInvoice` on an invoice that isn't a draft. |
| `ErrInvoicePaid` | Paying or voiding an invoice that's already paid. |
| `ErrInvoiceVoided` | Paying or voiding an invoice that's already voided. |
| `ErrInvoiceIncomplete`, `ErrInvalidDiscount` | Declared only. |

An invoice whose sums overflow an `int64` fails with an error wrapping `types.ErrOverflow`, and nothing is stored.

## Coupons

| Error | Returned when |
|-------|---------------|
| `ErrCouponNotFound` | No coupon with that code in the app, or that ID. |
| `ErrCouponInvalid` | A coupon without a code, an unknown type, a percentage outside 0 to 100, a negative amount, an amount coupon without a currency, a currency that doesn't match the plan's, an attempt to change a coupon's code, type, value, currency or app, or a `CouponValidator` plugin refusing it. |
| `ErrCouponNotStarted` | Applying a coupon before its `ValidFrom`. |
| `ErrCouponExpired` | Applying a coupon after its `ValidUntil`. |
| `ErrCouponExhausted` | The coupon has reached `MaxRedemptions`. |
| `ErrCouponAlreadyApplied` | The coupon is already on that subscription. |

## Providers

| Error | Returned when |
|-------|---------------|
| `ErrProviderNotConfigured` | A sync, import or webhook call with no payment provider plugin registered. `ListPaymentMethods` returns an empty list instead. |
| `ErrProviderNotFound` | No provider registered under the name asked for. |
| `ErrProviderSync` | A provider refused or failed an import. |
| `ErrProviderWebhook` | The provider's `HandleWebhook` returned an error. Both errors are wrapped. |

## Store

| Error | Returned when |
|-------|---------------|
| `ErrStoreNotReady`, `ErrStoreClosed`, `ErrTransactionFailed`, `ErrMigrationFailed` | Declared only. A failed migration comes back as the store's own error, such as `ledger/postgres: migration failed: ...`. |

## Helpers

```go
ledger.IsNotFound(err)  // ErrNotFound, ErrPlanNotFound, ErrSubscriptionNotFound,
                        // ErrFeatureNotFound, ErrInvoiceNotFound, ErrCouponNotFound
ledger.IsQuotaError(err) // ErrQuotaExceeded, ErrHardLimitReached, ErrSoftLimitReached,
                         // ErrNoEntitlement, ErrFeatureDisabled
ledger.IsRetryable(err)  // ErrMeterBufferFull, ErrStoreNotReady, ErrTransactionFailed,
                         // ErrProviderSync, ErrCacheInvalidate
```

`IsQuotaError` matches only declared-only errors, so it's false for anything the engine returns today. Of the `IsRetryable` set, the engine returns `ErrMeterBufferFull` and `ErrProviderSync`.

The package also has two error types for your own code. `ValidationError{Field, Message}` formats as `ledger: validation failed for <field>: <message>`, and `MultiError` collects errors with `Add`, `HasErrors` and `First`. The engine doesn't return either.

## HTTP status codes

Ledger serves no HTTP API, so there's no status mapping in the engine. The Forge dashboard contributor maps these errors to contract error codes for the dashboard; see `extension/contract/errors.go`.
