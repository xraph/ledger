Everything lives in one module, `github.com/xraph/ledger`. Import the packages you need. This page lists what each one exports; the [pkg.go.dev reference](https://pkg.go.dev/github.com/xraph/ledger) has the doc comments, and the entity structs are spelled out field by field in [Entities](/docs/concepts/entities).

Options, all covered in [Configuration](/docs/concepts/configuration):

| Option | Default |
|--------|---------|
| `WithLogger(log.Logger)` (go-utils) | no-op |
| `WithPlugin(plugin.Plugin)` | none |
| `WithMeterConfig(batchSize int, flushInterval time.Duration)` | `100`, `5s` |
| `WithEntitlementCacheTTL(time.Duration)` | `30s` |
| `WithLifecycleInterval(time.Duration)` | `1m`; zero or less turns it off |
| `WithClock(func() time.Time)` | `time.Now` |
| `WithMetrics(metrics.Metrics)` (go-utils) | no metrics |
| `WithoutMigrate()` | migrate on `Start` |

Re-exports: `Money` and `Entity` (aliases for the `types` ones), `ID` and `Prefix` (aliases for the `id` ones), and the variables `USD`, `EUR`, `GBP`, `JPY`, `CAD`, `AUD`, `Zero`, `Sum` and `NewEntity`.

Errors: the sentinel errors, `IsNotFound`, `IsQuotaError`, `IsRetryable`, and the `ValidationError` and `MultiError` types. See [Error handling](/docs/concepts/errors), which also says which sentinels the engine actually returns.

## Entity packages

### `github.com/xraph/ledger/plan`

`Plan`, `Feature`, `Pricing`, `PriceTier` and `ListOpts`, plus:

```go
func (p *Plan) FindFeature(key string) *Feature
func (p *Plan) Allows(featureKey string, currentUsage int64) bool
```

| Type | Constants |
|------|-----------|
| `Status` | `StatusDraft`, `StatusActive`, `StatusArchived` |
| `FeatureType` | `FeatureMetered`, `FeatureBoolean`, `FeatureSeat` |
| `Period` | `PeriodMonthly`, `PeriodYearly`, `PeriodNone` |
| `TierType` | `TierGraduated`, `TierVolume`, `TierFlat` |

`plan.Store` is the plan slice of storage (`Create`, `Get`, `GetBySlug`, `List`, `Update`, `Delete`, `Archive`). Stores implement `store.Store` instead, which repeats these with entity-prefixed names.

### `github.com/xraph/ledger/feature`

The catalog: `Feature` and `ListOpts`, with its own `Status`, `FeatureType` and `Period` types and the same constant names as `plan`.

### `github.com/xraph/ledger/subscription`

`Subscription`, `Period` (`Start`, `End`), `Renewal` (what `OnSubscriptionRenewed` receives), `Stretch` and `Resume` (pause bookkeeping), `ListOpts`, `DueOpts` and `DueField`.

| Type | Constants |
|------|-----------|
| `Status` | `StatusActive`, `StatusTrialing`, `StatusPastDue`, `StatusCanceled`, `StatusExpired`, `StatusPaused` |
| `DueField` | `DueCancel`, `DueTrialEnd`, `DuePeriodEnd` |

`StretchColumns` and `StretchFromColumns` convert a `*Stretch` to and from four nullable time columns, for store implementations.

### `github.com/xraph/ledger/meter`

`UsageEvent` and `QueryOpts` (`FeatureKey`, `Start`, `End`, `Limit`, `Offset`). `meter.Store` lists the usage methods. The buffering lives in the engine, not here.

### `github.com/xraph/ledger/entitlement`

`Result` (`Allowed`, `Feature`, `Used`, `Limit`, `Remaining`, `SoftLimit`, `Reason`) and the cache interface `entitlement.Store` (`GetCached`, `SetCached`, `Invalidate`, `InvalidateFeature`).

### `github.com/xraph/ledger/invoice`

`Invoice`, `LineItem`, `ListOpts` and `OverdueOpts`.

| Type | Constants |
|------|-----------|
| `Status` | `StatusDraft`, `StatusPending`, `StatusPaid`, `StatusPastDue`, `StatusVoided` |
| `LineItemType` | `LineItemBase`, `LineItemUsage`, `LineItemOverage`, `LineItemSeat`, `LineItemDiscount`, `LineItemTax` |

The tier pricing the engine uses is exported:

```go
func ValidateTiers(tiers []plan.PriceTier, currency string) error // wraps ErrInvalidTiers
func ComputeOverage(tiers []plan.PriceTier, usage, included int64, currency string) (types.Money, error)
func SortTiers(tiers []plan.PriceTier) []plan.PriceTier

var ErrInvalidTiers = errors.New("invoice: invalid price tiers")
```

### `github.com/xraph/ledger/coupon`

`Coupon`, `Application` and `ListOpts` (`Active`, `Limit`, `Offset`). `CouponType` has `CouponTypePercentage` and `CouponTypeAmount`.

### `github.com/xraph/ledger/provider`

The `Provider` interface (see [Payment providers](/docs/subsystems/payments)) and three result structs:

## Shared packages

### `github.com/xraph/ledger/types`

```go
type Money struct {
	Amount   int64
	Currency string
}

func USD(cents int64) Money // also EUR, GBP, JPY, CAD, AUD
func Zero(currency string) Money
func Sum(values ...Money) Money // panics on mixed currencies; "usd" zero when empty

// Arithmetic. Add, Subtract, Min, Max, LessThan and GreaterThan panic on mixed currencies.
func (m Money) Add(other Money) Money
func (m Money) Subtract(other Money) Money
func (m Money) Multiply(qty int64) Money
func (m Money) Divide(divisor int64) Money // integer division; panics on 0
func (m Money) Percent(pct int) Money      // truncates toward zero
func (m Money) Negate() Money
func (m Money) Abs() Money

// Overflow-checked. Errors wrap ErrOverflow; a currency mismatch is an error too.
func (m Money) CheckedAdd(other Money) (Money, error)
func (m Money) CheckedSubtract(other Money) (Money, error)
func (m Money) CheckedMultiply(qty int64) (Money, error)
func (m Money) CheckedPercent(pct int) (Money, error)

// Comparison and formatting
func (m Money) IsZero() bool
func (m Money) IsPositive() bool
func (m Money) IsNegative() bool
func (m Money) Equal(other Money) bool
func (m Money) LessThan(other Money) bool
func (m Money) GreaterThan(other Money) bool
func (m Money) Min(other Money) Money
func (m Money) Max(other Money) Money
func (m Money) FormatMajor() string // "49.99"
func (m Money) String() string      // "$49.99"
func (m Money) MarshalJSON() ([]byte, error) // {"amount":..,"currency":..,"display":..}

var ErrOverflow = errors.New("types: money arithmetic overflow")
```

`Entity` holds `CreatedAt` and `UpdatedAt`, with `NewEntity()`, `Touch()`, `Age()`, `LastModified()`, `IsNew()` and `IsStale(d)`.

### `github.com/xraph/ledger/id`

```go
type ID struct{ /* unexported */ }
type Prefix string

func New(prefix Prefix) ID
func Parse(s string) (ID, error)
func ParseWithPrefix(s string, expected Prefix) (ID, error)
func ParseAny(s string) (ID, error)
func MustParse(s string) ID
func MustParseWithPrefix(s string, expected Prefix) ID

func (i ID) String() string
func (i ID) Prefix() Prefix
```

`PlanID`, `FeatureID`, `PriceID`, `SubscriptionID`, `UsageEventID`, `EntitlementID`, `InvoiceID`, `LineItemID`, `CouponID`, `CouponApplicationID`, `PaymentID` and `AnyID` are aliases for `ID`. Each but `AnyID` has a `NewXxxID()` constructor, and each but `AnyID` and `CouponApplicationID` has a `ParseXxxID(s)`. `ID` implements text, SQL and BSON marshalling. See [Identity](/docs/concepts/identity).

## Plugins

### `github.com/xraph/ledger/plugin`

`Plugin`, the hook interfaces (`OnInit`, `OnShutdown`, `OnPlanCreated`, `OnPlanUpdated`, `OnPlanArchived`, `OnFeatureCreated`, `OnFeatureUpdated`, `OnFeatureArchived`, `OnFeatureDeleted`, `OnSubscriptionCreated`, `OnSubscriptionChanged`, `OnSubscriptionCanceled`, `OnSubscriptionCancelScheduled`, `OnSubscriptionExpired`, `OnSubscriptionRenewed`, `OnSubscriptionTrialEnded`, `OnUsageIngested`, `OnUsageFlushed`, `OnEntitlementChecked`, `OnQuotaExceeded`, `OnSoftLimitReached`, `OnInvoiceGenerated`, `OnInvoiceFinalized`, `OnInvoicePaid`, `OnInvoiceFailed`, `OnInvoiceVoided`, `OnInvoicePastDue`, `OnProviderSync`, `OnWebhookReceived`), and the strategy interfaces (`PricingStrategy`, `UsageAggregator`, `TaxCalculator`, `InvoiceFormatter`, `CouponValidator`, `PaymentProviderPlugin`).

`Registry` (from `NewRegistry()`) is what the engine uses to dispatch. You don't normally need it. [Custom plugin](/docs/guides/custom-plugin) says which hooks fire and when.
